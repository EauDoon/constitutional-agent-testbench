          Module index and direct imports
          

          Input boundaries · common.py
          Read bounded JSON and serialize stable output. Imports none in this map.
          

          Policy schema · policy.py
          Validate the declared version, field paths and rule kinds. Imports common.
          

          Rule evaluator · evaluator.py
          Compile rules and produce a verdict and reason code for each rule. Imports common, policy.
          

          Fixture suite · suite.py
          Check each fixture against its expected verdict and optional rule assertions. Imports common, evaluator, policy.
          

          Reason coverage · coverage.py
          Count observed outcomes and identify missing reason codes. Imports evaluator, policy, suite.
          

          Policy migration · compare.py
          Compare individual rules and case verdicts across two policies. Imports common, policy, suite.
          

          Peer ordering · precedence.py
          Check whether changing the order of declared peers changes the evidence. Imports common, evaluator, policy.
          

          Receipt verification · receipt.py
          Bind the input digests to an evaluation and recompute the binding. Imports common, evaluator, policy.
